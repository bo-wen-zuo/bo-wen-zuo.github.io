Projects

  • Test-time Scaling with LLMs
    • Scaled LLM inference for math reasoning and code generation by developing a dynamic compute-allocation algorithm that replaced uniform inference budgets, which achieved consistent performance gains across evaluated benchmarks. Extended the base method with bandit-based adaptive allocation, improving robustness on skewed, hard-question-dominant distributions; this work became an ICLR 2026 accepted paper.
    • Developed an adaptive allocation framework that jointly decides where to spend test-time compute and how to generate, conditioning on successful responses to semantically related queries as evolving in-context demonstrations; this work was accepted to Findings of ACL 2026.
  • Diffusion Language Models
    • Proposed a two-stage test-time scaling method for diffusion language models: a fast base sampler handles easy questions, and frequency-aware remasking, which tracks how often token predictions change across denoising steps, targets the remaining hard ones. On LLaDA-8B-Instruct and Dream-7B-Instruct, achieved up to 7.4% accuracy gains on MATH-500 and up to 11.18% coverage gains on HumanEval; this work was accepted to NeurIPS 2026.
  • Post-training
    • Developed stepwise risk-sensitive GRPO for diffusion language models to encourage exploration and improve reasoning during RL post-training; this work appeared at the COLM Non-AR Workshop 2026.
    • Analyzed why on-policy distillation fails to transfer capabilities between language models, identifying vanishing learning signals that cause early loss plateaus with larger-scale teachers on code generation and math reasoning.
  • 3D Talking Face Generative Models
    • Reproduced training of a 3D talking-face model on Meta’s Multiface dataset using PyTorch3D.
    • Added Multiface facial textures to models that originally produced texture-free outputs.
    • Built an interactive pipeline using Google TTS and the ChatGPT API to generate talking-face video responses.
    • Worked with multimodal embeddings (identity, audio, images, and text) in encoder–decoder architectures.
